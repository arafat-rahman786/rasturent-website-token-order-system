Project Overview

BurgerBite

ফিচার ও ডেভেলপমেন্ট জার্নি

BurgerBite একটি Restaurant Ordering ও Token Management System। এই প্রজেক্টে Food Ordering, Cart Management, Menu Management এবং Order Tracking-এর মতো বাস্তব সমস্যার সমাধান করার চেষ্টা করা হয়েছে।

01 প্রজেক্টের ফিচারসমূহ

  1. ১.

    আধুনিক ও Responsive Restaurant Website ডিজাইন।

  2. ২.

    খাবারের Menu, Category, Image, Rating ও Price প্রদর্শন।

  3. ৩.

    Shopping Cart — Quantity পরিবর্তন, Item Remove ও Total Price হিসাব।

  4. ৪.

    Wishlist — পছন্দের খাবার সংরক্ষণ ও পরিচালনা।

  5. ৫.

    Admin Dashboard — Product Add, Edit, Update ও Manage।

  6. ৬.

    Live Preview — Product-এর ডিজাইন পরিবর্তনের Preview।

  7. ৭.

    Parcel Order ও Table Booking-এর আলাদা ব্যবস্থা।

  8. ৮.

    Order Token তৈরি ও Order Data পরিচালনা।

  9. ৯.

    Live Token Countdown ও Preparation Time অনুযায়ী অপেক্ষার সময় গণনা।

  10. ১০.

    API Integration-এর মাধ্যমে Product ও Cart Data পরিচালনা।

  11. ১১.

    Geolocation API ব্যবহার করে Customer Location নেওয়ার ব্যবস্থা।

  12. ১২.

    Mobile, Tablet ও Desktop-এর উপযোগী Responsive Layout।

02 ডেভেলপমেন্টের সময় আমাদের সংগ্রাম

  1. Cart Data Management: Quantity, Total Price এবং Cart Data সঠিকভাবে পরিচালনা করা।
  2. Multiple User সমস্যা: API-তে একাধিক User-এর Cart আলাদা রাখার বিষয়টি বোঝা ও পরিচালনা করা।
  3. Dashboard Edit System: পুরোনো Data Form-এ দেখানো এবং পরিবর্তিত Data API-তে Update করা।
  4. API ও Data Structure: 404 Error, ভুল URL, JSON Format ও Array of Objects-এর সমস্যা Debug করা।
  5. Checkout ও Token Logic: Customer Information, Product Quantity ও Total Price একসঙ্গে পরিচালনা করা।
  6. Parcel ও Table Booking: আলাদা Form ও Order Flow সঠিকভাবে পরিচালনা করা।
  7. Live Countdown: Preparation Time ও Quantity অনুযায়ী অপেক্ষার সময় গণনার Logic তৈরি করা।
  8. Location System: Geolocation API ও Google Maps Link নিয়ে কাজ করা।
  9. Wishlist ও LocalStorage: Data সংরক্ষণ এবং Refresh-এর পর সঠিকভাবে দেখানোর ব্যবস্থা করা।
  10. Debugging ও Logic Building: async/await, try/catch, reduce(), FormData এবং API Response-এর সমস্যা সমাধান করা।

আমাদের শেখা

এই প্রজেক্টের মাধ্যমে UI Development-এর পাশাপাশি API Integration, Data Management, Asynchronous JavaScript, Debugging এবং Problem Solving-এর অভিজ্ঞতা অর্জনের সুযোগ হয়েছে।
